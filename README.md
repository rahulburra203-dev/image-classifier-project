# Cat vs Dog Image Classifier 🐱🐶

This project is a Deep Learning based Image Classifier developed using TensorFlow and Python.

The model can classify images as either Cat or Dog using a Convolutional Neural Network (CNN).

## Features
- Deep Learning Image Classification
- Cat vs Dog Prediction
- TensorFlow/Keras Model
- Image Preprocessing
- Interactive Prediction System
- Training and Testing Support

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
